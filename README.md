# aimgpaコマンド
![test](https://github.com/YO-1015/robosys2026/actions/workflows/test.yml/badge.svg)

大学の成績(GPA)について、使用者が目標とするGPAを達成するためには今学期のGPAがいくつ以上である必要があるかを計算するコマンドです。  
また、本コマンドは4.0が満点となるGPA制度にのみ対応しています。

以下の4つの数値を(入力例)のように入力して使用します。  
- 今学期までのGPA  
- 修得済単位数  
- 今学期履修中の単位数  
- 目標とするGPA  
(入力例)  
```
$ echo 2.5 60 20 2.8 | ./aimgpa
```

## インストール方法
以下のコマンドを実行してリポジトリをクローンし、ディレクトリに移動します。
```
$ git clone https://github.com/YO-1015/robosys2026.git  
$ cd robosys2026
```

  - テスト済みバージョン: 3.10〜3.14
